# 模板视频调研笔记(2026-10-19)

研究方法:3 个并行研究代理,20+ 轮网络检索。来源:东方财富、36氪、虎嗅、百科、湖北日报、人人都是产品经理、知乎等(完整来源见会话记录)。

## 一、"不烧心"是什么

- **2026年10月初爆火的热梗**,出自红果短剧 App 批量生成的 **AI 市井漫剧**(餐饮经营题材),非歌曲、非真人桥段
- 抖音锚点爆款:漫剧《包子里的真心》(不鸣文化等出品),播放增量 13.66 亿
- #不烧心# 话题:10月2日上热搜 → 10月16日达 **28.4 亿次播放、48.5 万投稿**
- **五步固定剧情**:良心摊主用好料不降价 → 劣质同行低价抢客 → 顾客流失主角被嘲 → 劣质摊翻车 → 顾客回流
- **固定台词**:"贵是贵了点,但吃了不烧心" / "宁可少挣点,规矩不能坏" / "先把规矩立住,路才能越走越宽"
- **固定 BGM**:《囚笼》(最典型)、《撕咬进行曲》《反派烧气救场》《樱花草》《困兽》《利维坦》
- **二创形态**:换行业(万物皆可不烧心)、换剧名仿冒、真人仿拍、反向黑化版("纯烧心")、线下商户实拍

## 二、模板视频的发现规律(为什么搜"模板"没用)

抖音站内**没有"模板"这个品类**。搜"模板"命中剪映教程/设计师营销内容。翻拍视频从不自称模板,它们的聚合锚点是:

1. **话题标签页**(#梗名#,按最新/最热列出全部投稿)
2. **原声/音乐聚合页**(同 BGM ≈ 翻拍全集列表,最符合"连 BGM 都一样")
3. **拍同款/剪同款按钮**(官方复制入口)
4. **评论区对暗号**(固定台词接龙、"求bgm"高频评论 = 模板指纹)
5. **热榜/低粉爆款榜**(低粉账号套模板也能爆 → 模板视频富集区)

**有效搜索词类型**:①梗名原词 ②梗名+二创/翻拍/仿拍/原声/反向 ③固定台词原句 ④BGM/歌名 ⑤品类词(AI漫剧、压抑 开挂 打脸)。

**程序化发现策略**:种子信号提取{话题名, 原声名, 固定台词} → 每个信号一条 query → 话题页/原声页收割 → 标题含台词 = 高置信变体 → 多模态抽帧验证同构。

## 四、采集操作要点

- 抖音**网页搜索必须登录**才有完整结果(hunter 已用可见 Edge + 扫码登录一次解决)
- 每模板取 10 条:建议最热 5 + 最新 5,覆盖不同作者
- 短剧类加"仿拍/二创/同款",歌曲类加"翻唱/卡点",AI 类加"教程/AI"
- 下载后按 BGM 名或固定台词归档去重;多模态抽帧验证同构(GLM)
